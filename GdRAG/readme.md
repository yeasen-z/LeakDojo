# Green Dinosaur RAG based on LangChain

- data: raw data of database
- models: embedding model and local llm checkpoints
- configs: diff rags sys config file
- rag: core python files
- retrieval_stores: RAG base
- demos: simple tests


# 环境搭建
```bash
pip install langchain transformers sentence-transformers faiss-cpu
```
